# UX Solution Template

## 1. UX-задача и критерий завершения

Изменение пользовательского опыта, момент входа и наблюдаемый результат.

## 2. Концепция и rationale

3–6 ключевых решений. Для каждого: решение → основание → ценность → компромисс.

## 3. Journey и сценарии

Короткие этапы: намерение → информация → действие → ответ системы → риск.

### Happy path

Нумерованный путь от входа до результата.

### Значимые альтернативы

Только развилки, ошибки и возвраты, меняющие решение.

## 5. Information hierarchy и surfaces

Главный сигнал → смысл → действие → детали → meta. Обоснуй только реально нужные Page, registry, situational overview/dashboard, modal, drawer и inline layers. Для registry/monitoring page явно зафиксируй: нужен ли aggregate/interactive overview перед detailed list, какой вопрос он отвечает и связан ли с filters/drill-down.

Если решение адаптирует существующий product pattern или предлагает новую композицию, укажи `pattern basis` и rationale без пикселей и визуальных токенов.

## 6. Состояния и feedback

Только релевантные loading, empty, error, partial, success и action progress.

## 7. Роль ассистента

Для валидных сценариев: момент → намерение → контекст → ответ/действие → подтверждение → fallback. Если не нужен — одна причина.
