# Sources — bounded local source policy

В переносимом комплекте включены **полные frontend-нормативы** в `sources/frontend-rules/`.

**Не включены:** OpenSpec, аналитические технические спецификации, код UI Kit, репозитории и графические assets. Это внешние evidence-источники, доступные только при реальной настройке `~/.gigacode/product-evidence.yaml`.

- Наличие пути или URL в YAML **не равно** прочитанному источнику.
- Проверяй доступность, разрешения, версию, актуальность и применимость в текущем проекте.
- Если нужный источник недоступен — явно помечай `NOT_CONNECTED`/`BLOCKED_BY_SOURCE`, не выдумывай API или подтверждённый release status.
- Предметный контекст внутри `product-system/` сохраняется как исторически нормализованная модель с оговоркой о production-проверке.
