# Подключение NORM

- `~/.gigacode/product-contexts.yaml`: абсолютный `contexts.norm.provider.root` к папке `context/`, `manifest: product-system/context-manifest.yaml`.
- `<project>/.gigacode/product-context.yaml`: `version: 1`, `context_id: norm`.
- `~/.gigacode/product-evidence.yaml`: разрешённые локальные пути или URL к спецификациям, UI Kit, исходникам и визуальным материалам. Не публиковать заполненный файл.

Смотри подробности в корневом README.
