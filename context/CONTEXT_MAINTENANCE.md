# Поддержание контекста

При обновлении сервиса синхронизируй документ в `02_domain/services/`, реестры в `02_domain/registry/` и карту сервисов. Для «Мер» сохраняй все Q/R ID и открытые противоречия. Для UI следи за согласованностью `patterns/runtime/` и `patterns/specs/`, особенно Drawer.

Внешние OpenSpec, UI Kit, репозитории и брендовые визуальные материалы не копировать в этот пакет. Они разрешаются через локальный `product-evidence.yaml`. Каждый раз проверять `context/tools/validate_context.py`, а перед публикацией — ИБ.
