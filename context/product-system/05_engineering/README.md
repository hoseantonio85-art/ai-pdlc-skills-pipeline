## Engineering standards (05–07)

Полные дополнительные инженерные нормативы размещены здесь как часть продуктовой системы. Основной универсальный workflow и контракты остаются в `agent/.gigacode/skills/05-07-frontend-standards/`.

Документы подключены через `context-manifest.yaml` к стадиям frontend planning, implementation и review. Не загружать на этапах постановки, UX, прототипа или SDD.

Внешние исходники и UI Kit подключаются отдельно через пользовательский `product-evidence.yaml`; наличие пути не доказывает чтение источника.
