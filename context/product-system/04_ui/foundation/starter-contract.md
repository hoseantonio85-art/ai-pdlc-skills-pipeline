# Starter: границы реализации и адаптация

`product-system/04_ui/starter/` — исполняемый пример Event/AI registry. Это не универсальный генератор всех сервисов. `data-scenario="event"` включает события; `ai` — историю запусков. Для простого переключения без правки файла используются URL `index.html` и `index.html?scenario=ai` (параметр `scenario` имеет приоритет перед `data-scenario`). Demo controls: `?demo=1`, либо `?scenario=ai&demo=1`. Fixtures и подписи в prototype.js адаптируются по утверждённому UX Solution. Даты фиксированы для воспроизводимого сравнения, загрузка и анализ имитируются.

## Файлы

- styles.css: базовая структура и optional form primitives.
- norm-components.css: единственный слой продуктовых tokens и текущей геометрии; подключается после styles.css. Адаптация должна менять существующее правило, не накапливать overrides в конце файла.
- norm-components.js: экранирование текста, карточка event/AI, фильтрация, общий lifecycle поверхностей.
- prototype.js: сценарий, fixtures, связь контролов и данных.
- index.html: shell и слоты. Все пять файлов и каталог assets/ обязательны; локальный fallback `agent/.gigacode/skills/03-build-visual-html-prototype/assets/norm-html-starter/` должен совпадать побайтно с `context/product-system/04_ui/starter/`.

## Поверхности

`Norm.open(html, trigger, {type:'object'})` — самостоятельный объект без общего Footer. `type:'form'` — короткая create/edit форма с Footer. `Norm.drawer(html, trigger, {scope:'container'})` — подчинённая задача; при наличии родителя перекрывает весь его shell, иначе открывается от viewport. Явный `scope:'viewport'` доступен по UX-решению. История и помощь — Drawer; связанный самостоятельный объект — Object Modal.

Один менеджер обслуживает focus trap, inert, **Escape с учётом типа поверхности**, scroll lock, возврат фокуса и восстановление родителя. Для **Drawer Escape выключен по умолчанию**; можно явно передать `{closeOnEscape:true}` в `Norm.drawer` для конкретного сценария. Для Object Modal/Form Escape остаётся включённым как в исходном демонстрационном runtime. Закрывается только верхний слой. Если trigger карточки заменён при render, фокус ищет ту же запись по data-id, затем основной CTA. Dialog получает доступное имя из h2. Контент без кнопок фокусирует сам dialog. Не добавлять отдельные document-level Escape handlers в сценарий.

## Состояние

Scope AND search AND advanced filters; быстрые статусы внутри группы связаны OR. Drawer редактирует draft: Reset очищает draft; Apply коммитит; Close отбрасывает. Escape не закрывает Drawer по умолчанию; при явном включении Escape действует как закрытие только верхнего Drawer и отбрасывает несохранённый draft **в этом демонстрационном сценарии**, но это не универсальное правило для dirty forms. Непустой поиск остаётся раскрытым, пока запрос не очищен. Empty recovery очищает query и возвращает demo mode default; error retry сохраняет query. Demo controls доступны через `?demo=1`, их active/aria-pressed отражают состояние.

## Покрытие

Norm.card реализует Event/AI slots. Measure, Risk, knowledge и campaign описаны contracts, но требуют отдельной адаптации — наличие варианта в индексе не означает готовый widget. Источник документа в примере — representative destination, не PDF renderer. Полная доменная форма, dirty guard, серверная загрузка, permissions и точные icon/font assets реализуются по задаче. Не объявлять их готовыми возможностями starter.

Мобильное скрытие sidebar и breakpoints — гипотеза prototype. Если acceptance требует навигацию между сервисами на mobile, добавить доступный navigation entry; текущий пример проверяет одну рабочую поверхность.

## Логотипы и action dock (7.0.2)

`assets/icon_logo.svg` — исходный демонстрационный знак продукта; `assets/gradient-logo.svg` — исходный знак AI. Это визуальные assets из прежнего prototype starter, **не** подтверждение прав на публичное распространение. Для рабочего переноса копировать вместе со starter, не заменять геометрической имитацией; при публикации сверить права на распространение assets. `Norm.brand()` использует знак НОРМ; `Norm.brand('ai')` — AI. Изображения декоративны внутри уже подписанного бренда или кнопки с aria-label.

В action dock текстовые кнопки растягиваются на всю свободную ширину внутренней области (`flex: 1; min-width: 0`); несколько кнопок делят её поровну. Иконочная AI-кнопка сохраняет 40×40px и не растягивается. Сохранять padding и gap; не оставлять пустую левую область, как у выравнивания коротких кнопок вправо.


## Проверка и граница безопасности (восстановление 2026-10-28)

- Восстановлен полный HTML/CSS/JS стартер: sidebar, реестры Event/AI, карточки, поиск, фильтры, состояния, статистика, Object Modal, Drawer, создание и повторный запуск, менеджер вложенных поверхностей.
- Fixtures имеют **явно синтетический характер**: ФИО и персональные демонстрационные инциденты заменены, настоящие данные не подгружаются. Весь runtime локальный, без CDN/внешних API.
- Логотипы и палитра сохранены из прежнего starter по решению владельца рабочих материалов; перед **публичной** публикацией требуется проверка прав и ИБ.
- Спецификация общего NORM/ORM Drawer описывает дизайн-ориентиры. Текущий starter реализует **конкретный сценарий NORM** и не заявляет полную поддержку ORM theme, многослойных размеров или production UI Kit.
