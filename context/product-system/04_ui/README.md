# UI-контекст NORM

- `foundation/`: composition, shell, entity registries.
- `visual/`: визуальная иерархия, плотность, адаптация композиций.
- `patterns/`: композиционные паттерны, `runtime/` и общие shell `specs/`.
- `organisms/`: составные UI-паттерны и registry.
- `starter/`: **полный интерактивный HTML-starter NORM Event/AI** (исходные стили, assets, сценарии и surface lifecycle; fixtures синтетические). Это не production UI Kit, и сценарии других сервисов требуют адаптации.

Восстановлены **только два SVG-знака внутри HTML-starter** и палитра, без внешнего UI Kit package, frontend snapshots, технических OpenSpec и репозиториев. Права на публичное распространение SVG необходимо отдельно подтвердить. Реальный API UI Kit доступен только после подключения разрешённых источников на рабочем компьютере.
