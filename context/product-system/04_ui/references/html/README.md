# Локальные HTML-сцены для визуальной композиции

Сохранены две **авторские концептуальные иллюстрации** из исходного контекста, без подключённых API, спецификаций или кода продуктовых репозиториев:

- [situational-overview/index.html](./situational-overview/index.html) — пример ситуационной аналитики над результатами списка;
- [norm-vertical-slice/index.html](./norm-vertical-slice/index.html) — пример связи реестра, карточек, Object Modal и Drawer.

**Данные и события в макетах синтетические**, не факт реальных случаев, актуального production или пользовательских инцидентов. Сцены являются visual/composition evidence, **не определяют DOM, API, реальные токены, бизнес-правила или доступы**. Текущие UX/UI-инварианты имеют приоритет, включая актуальный Drawer (Escape default off). На Stage 03 сначала использовать product starter и Foundation; сцены открывать только когда они помогают текущей композиции.
