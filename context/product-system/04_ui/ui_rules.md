# UI rules — нейтральная базовая система

- Использовать компоненты установленного UI Kit и его реальные tokens, не придумывать exports.
- Сохранять чёткую визуальную иерархию: заголовок, контекст, действие, содержание.
- Header/Body/Footer должны иметь предсказуемую прокрутку.
- Выбирать композицию по задаче, а не копировать все референсы.
- Поддерживать responsive layouts и keyboard accessibility.
- Дизайн реального продукта подключается локальным внешним контекстом; в этой поставке его нет.
