# UI patterns

Начинай с `pattern-registry.yaml`, затем открывай **выбранный runtime** и, если необходимо, полный shell/drawer spec. Не загружай всё подряд. Паттерны — проектные правила, не ready-to-use API UI Kit.

Для Drawer актуальны `runtime/drawer.md` и `specs/drawer.md`, темы NORM и ORM имеют разные свойства Close и каскада. Внешние исходники и UI Kit читаются только в рабочем окружении через YAML.
