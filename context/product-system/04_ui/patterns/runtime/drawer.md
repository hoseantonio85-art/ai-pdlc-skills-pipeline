# Drawer — runtime pattern NORM/ORM

> Краткий контракт из [основной спецификации](../specs/drawer.md); дизайн-правила, не production API.

- Drawer — вторичная задача при сохранении Page/Modal/Drawer; самостоятельный основной объект → Modal/Page.
- `theme: NORM|ORM` независимо от `scope: viewport|container` и системного `size: S|M|L|XL` (608/720/840/1184 px).
- **NORM:** surface скруглена со всех сторон, Close в Header; новый каскадный слой того же размера или на один пресет меньше.
- **ORM:** surface у правого края scope, внешний Close принадлежит композиции; все новые слои одного размера; соседняя вертикальная навигация опциональна при заданном порядке коллекции.
- `container` перекрывает **Header, Body, Footer** Modal; `viewport` — окно, включая Modal если это нужно (в ORM допускается).
- Каждый новый слой имеет **свой overlay**; нижние сохраняются. Close закрывает только верхний Drawer. **Нет жёсткого максимума два:** NORM обычно до 3, 4–5 с обоснованием; ORM после третьего осторожно.
- **Escape по умолчанию выключен**, опциональное включение — только для верхнего слоя. Overlay click и dirty-state UX **не утверждены**.
- Back/replace content **не утверждены универсально**: не добавляй Back автоматически. Редактирование текущего объекта не равно новому слою.
- Header/опциональный Footer закреплены, прокручивается Body. Footer — только для общих действий.
- Responsive, status/overlay tokens, animation/focus/accessibility глубоко вложенных слоёв требуют проверки; старые 32/24/44 не универсальные tokens.
