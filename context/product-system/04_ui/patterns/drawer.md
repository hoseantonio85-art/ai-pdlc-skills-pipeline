# Drawer — общий pattern

Подчинённая задача при сохранении основного экрана. Верхняя поверхность управляет взаимодействием, закрытие возвращает пользователя к ранее открытой области.

- Scope: viewport или внутри родительской поверхности, если компонент допускает оба режима.
- Header остаётся видимым; Body — scroll; Footer показывать только для общих действий.
- Каскад возможен при ясной цели, нельзя автоматически делать новый слой для каждого шага.
- Close обрабатывает текущий верхний слой; overlay click, Escape и dirty-state должны быть явно определены сценарно и проверены по UI Kit.
- Не использовать неподтверждённые пиксельные значения, глубины стеков или свойства API.
