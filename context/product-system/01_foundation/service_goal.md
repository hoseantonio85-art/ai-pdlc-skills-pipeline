# Основа продукта — шаблон

**Статус: демонстрационная основа.** Продуктовые факты, реальные роли, ограничения и источники не включены в публичный pipeline. Заполнять из проверенного локального источника, выбранного для конкретного проекта.

- Пользовательские задачи и цели — определяются для конкретного продукта.
- Данные, статусы, права, формулы и процессы нельзя выводить из этого шаблона.
- Изменения подтверждаются владельцем продукта и актуальными источниками.
- Если не хватает сведений для требования — пометить `NEEDS_SOURCE` / `BLOCKED_BY_SOURCE`.
