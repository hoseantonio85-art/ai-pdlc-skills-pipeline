# Текущее состояние продуктовой модели

**Статус:** восстановленная историческая продуктовая документация, не live runtime и не подтверждённый релиз.

## Что в пакете есть

14 описаний продуктовых сервисов, 56 capabilities, роли, бизнес-правила, UX/UI паттерны и подробная история «Мер» с открытыми вопросами. Они описывают предметную модель для постановки и UX, но не доказывают доступность функций на production.

## Что отдельно требуется подтвердить

- Что именно развернуто и включено в текущем окружении, какие feature flags активны;
- Матрицу прав конкретных ролей и шаги бизнес-согласования по актуальным источникам;
- Реальные backend API, frontend route map и актуальные версии UI Kit;
- Рабочее соответствие референсов и текущего продукта.

## Приоритет

Утверждённые факты владельца продукта и свежие разрешённые первоисточники (`~/.gigacode/product-evidence.yaml`) уточняют историческую модель. Не считать ранее собранную документацию актуальным свидетельством production.
