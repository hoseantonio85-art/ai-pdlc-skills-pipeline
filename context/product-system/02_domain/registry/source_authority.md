# Приоритет и статус источников

- Этот контекст — историческая предметная/UX-модель NORM, полезная как отправная точка. Это **не доказательство актуального production**.
- Решения владельца продукта и методологов являются основанием для будущего поведения, если имеют дату и источник.
- Внешние спецификации (при наличии доступа через `product-evidence.yaml`) подтверждают требования, но не факт развёртывания.
- Реальный код целевого репозитория и доступные логи/тесты могут подтвердить выбранный снимок реализации, не обязательно production.
- Реальный runtime требует отдельного подтверждения релиза и прав.
- Визуальные референсы/прототипы подтверждают композицию, но не права, статусы, API и бизнес-формулы.

Для «Мер» историческое исследование ранее проводилось по исходникам и документам, **но они не входят в переносимую сборку**. Все выводы о кодовом AS IS требуют повторной проверки, а противоречия хранятся в `measures_questions.md`. При недоступном источнике — `NEEDS_SOURCE`, без домыслов.
