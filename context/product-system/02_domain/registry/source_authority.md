# Приоритет источников

1. Утверждённая цель задачи и решения владельца продукта.
2. Подключённый локальный контекст продукта и актуальные первоисточники; проверить реальные версии и права доступа.
3. Для реализации — фактический целевой репозиторий и установленная версия UI Kit.
4. Демо-материалы и примеры не являются сведениями о production.

Внешняя спецификация или код доступны **только после проверки пути/URL и чтения**. Не объявлять недоступный источник прочитанным.
