# Загрузка контекста

Подключи `~/.gigacode/product-contexts.yaml`, выбери контекст проекта из `<project>/.gigacode/product-context.yaml`, затем используй manifest `product-system/context-manifest.yaml` и профиль этапа.

Читай компактные реестры до полных документов, внешние спецификации и UI Kit только по необходимости. Если фактические источники не настроены — явно сообщи об этом и не выдавай примеры за продуктовые факты.
