## Сквозные связи

- Событие и риск могут быть связаны; меры управляют действиями по предотвращению или устранению последствий.
- Риски связаны с финансовыми эффектами и лимитной кампанией; мини-риски AI-агентов и агрегированный риск имеют разную ответственность.
- ИИ-агенты и продукты проходят оценку; документы и рекомендации помогают принять решение, но не заменяют подтверждение человеком.
- Контрагенты, источники, ассистент, мониторинг и справочники образуют связанные предметные области, но их права и текущий runtime должны проверяться отдельно.
- **Меры:** полноценное описание находится в [measures.md](measures.md), а открытые Q/R — в [реестре](../registry/measures_questions.md). Реестр сервисов не заменяет этот документ.

## Границы ответственности и сквозные сценарии

Эта карта описывает бизнес-связи, **не** маршрут технических API или устройство внутренней инфраструктуры. Владелец данных и фактические разрешения проверяются отдельно.

1. **Событие → последствия/расследование → связь с риском → переоценка или меры.** Связь не переносит ответственность за исходный объект.
2. **Риск → финансовые показатели → лимитная кампания → решение по лимиту и его использованию.** Нельзя смешивать показатель агрегированного риска с мини-рисками конкретного AI-агента.
3. **AI-агент/продукт → документы → оценочная задача → риск → рекомендации/меры.** Workflow зависит от типа оцениваемой сущности; не объединять их без утверждённого решения.
4. **Контрагент → договор → проверка → решение/документы.** Перекрывающиеся роли и права проверяются через разрешённые источники.
5. **Организация/пользователь/тариф → набор разрешённых действий.** UI-наличие кнопки не доказывает разрешение на бизнес-операцию.

## Алгоритм для скиллов

Сначала выбери сервис по `../registry/service_registry.yaml`, затем прочитай соответствующее полное описание. При потребности во внешнем подтверждении обратись к разрешённым источникам через `~/.gigacode/product-evidence.yaml`; отсутствие источника не восполняй догадкой. На этапе UX не заменяй утверждённую предметную логику визуальной композицией.
