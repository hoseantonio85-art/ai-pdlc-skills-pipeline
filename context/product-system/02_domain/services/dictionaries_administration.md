# Справочники и администрирование

**Статус знания:** исторически описанная предметная область, требует проверки актуальной спецификации.

## Назначение
Единое администрирование справочных значений, доступных пользовательским доменам.
## Объекты и сценарии
- Tenant-scoped и общие справочники, линейные и иерархические классификаторы, версии и история.
- Каталог, открытие справочника, поиск/фильтр, отображение неактивных значений.
- Добавление, переименование, перемещение, деактивация узлов с проверкой глубины дерева.
- Сохранение с optimistic locking, импорт/экспорт, распространение и кэширование для потребителей.
## Границы
Административный UX каталога не равен техническому API справочников; изменение справочника может менять значения форм в связанных сервисах.
## UX-смысл
Не представлять все справочники статичными select: есть полноценные режимы редактирования дерева/линейного списка и управление версиями.

## Внешняя проверка

Точные права, состояния, поля и формулы необходимо проверять по разрешённым спецификациям через `product-evidence.yaml`.
