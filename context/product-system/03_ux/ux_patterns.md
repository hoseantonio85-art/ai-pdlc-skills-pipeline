# UX patterns — общие решения

- **Page** — длительная самостоятельная работа.
- **Object Modal** — сфокусированный просмотр и основное действие над объектом.
- **Drawer** — вторичная задача при сохранении исходного контекста.
- **Filter panel** — фильтрация списка, различать draft и applied состояния.
- **Entity list** — набор объектов с поиском/фильтром и понятным переходом в детали.
- **AI assistant** — объяснение с явно обозначенными источниками и неопределённостью, без выдуманного reasoning.

Эти паттерны являются общими шаблонами, не спецификацией конкретного продукта.
