# UX principles — общие правила

- Сначала пользовательская задача и outcome, затем композиция и компоненты.
- Состояния loading, empty, error, denied и success должны быть понятными.
- Действия и информация группируются по смыслу; не дублировать элементы управления.
- Не скрывать критические последствия решений и несохранённые изменения.
- Для недоказанных утверждений маркировать assumption / unknown.
- Accessibility и навигация клавиатурой — часть проектного решения.
